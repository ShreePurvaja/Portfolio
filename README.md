## 🚀 Overview

A personal developer portfolio built with modern vanilla web technologies and an optional Python Flask backend server. Features a dark obsidian / crisp light theme system, interactive particle physics canvas, project architecture modals, dynamic AI prediction simulators, and verified achievement showcases.

## 🛠️ Tech Stack

* **Frontend**: HTML5, Vanilla CSS3 (Custom Design System, Glassmorphism, Neon Aura accents), Vanilla JavaScript (ES6+)
* **Backend**: Python 3.x, Flask (Local Simulation Server)
* **Assets & Media**: Standalone local images, SVGs, and responsive vectors

## 💻 Running Locally

### Option 1: Direct Browser Launch
Simply open `index.html` in any modern web browser. All styles, scripts, particle animations, and UI components run client-side without any build tools.

### Option 2: Python Flask Local Server
1. Clone this repository:
   ```bash
   git clone https://github.com/ShreePurvaja/Portfolio.git
   cd Portfolio
   ```
2. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Launch the local server:
   ```bash
   python app.py
   ```
4. Open [http://localhost:5000](http://localhost:5000) in your browser.
